# BioMed Sales Mastery: Healthcare & Biotech Executive Sales Academy

An executive-level commercial training academy, interactive simulation environment, and career accelerator designed to prepare individuals for high-performance sales in **Medical Devices**, **Biotechnology & Specialty Oncology**, **Specialty Pharmaceuticals**, and **HealthTech & SaMD (Software as a Medical Device)**.

This platform is built around enterprise sales methodologies (MEDDPICC, SPIN Selling, The Challenger Sale, Command of the Message) and adapts them directly to hospital operating rooms, hospital Value Analysis Committees (VAC), and health system C-Suites.

## 🌟 Elite Methodologies: Shelby Haas & Global Corporate Titans

### 1. Shelby Haas (She Sells Academy) Modern Sales Architecture
- **Radical Detachment & Unstoppable Mindset**: Shifting from needy commission-chasing to diagnostic evaluation. The rep evaluates whether the healthcare system qualifies for the solution.
- **Reverse Selling & Question-Led Discovery**: Moving away from feature-dumping scripts. Asking calibrated questions that lead the surgeon/executive to articulate their own dissatisfaction and reasons to purchase.
- **The Shelby Haas 5-Step Objection Reframing Framework**:
  1. *Exhaust & Deeply Listen*: 2-second silence after objection; disarms anticipation of conflict.
  2. *Validate & Mirror Without Agreement*: "That makes complete sense... you'd be crazy to switch just to try a new gadget."
  3. *Clarifying Diagnostic Question*: Isolating the underlying 10% edge-case pain.
  4. *Honest Value Reframe & Cost of Inaction*: Highlighting complication risk and operational turnover lag.
  5. *Resolution Check & Trial Close*: "If I had our sterile tray on standby for just one case, would you be opposed to evaluating it yourself?"

### 2. High-Stakes Corporate Titans Integrated
- **Chris Voss (Never Split the Difference)**: Tactical Empathy, Late-Night FM DJ vocal downward inflection, Labeling ("It seems like..."), and Calibrated "No-Oriented" Questions ("Would it be ridiculous to review one case?").
- **Keenan (Gap Selling)**: Hard Fact Baselines vs Desired Future State, The 3 Levels of Pain (Technical, Business EBITDA, Personal Surgeon Stress).
- **Matt Dixon & Brent Adamson (The Challenger Sale)**: Commercial Teaching, Constructive Tension, and Leading TO unique differentiators.
- **Corporate Biotech & MedTech Giants**:
  - *Stryker*: Gallup CliftonStrengths/Talent+ behavioral interrogation, 24/7 trauma grit, OR scrub etiquette.
  - *Medtronic*: Value-Based Healthcare, risk-sharing episode-of-care models, and C-Suite IDN contracting.
  - *Genentech/Roche*: Kaplan-Meier survival curve analysis, hazard ratios, Part B Buy-and-Bill practice economics.
  - *Intuitive Surgical*: Multi-million capital robotics acquisition paired with recurring consumable instrument turnover.

## 🚀 Quickstart & Installation

```bash
# Clone the repository
git clone https://github.com/taliabout/BioMed-Sales-Mastery.git
cd BioMed-Sales-Mastery

# Install dependencies
npm install

# Run the full-stack server (Vite + Express)
npm run dev

# Build for production
npm run build
npm start
```
